# Запись демо-роликов для анонсов

Инструкция по запуску скрипта: `scripts/demo/README.md`.

Сценарий рисуется файлом, телефон проигрывает его по таймлайну, экран пишет `adb shell screenrecord`,
затем собираются версии EN и RU с субтитрами. Человек перед камерой не нужен.

```bash
cd scripts/demo && npm install        # один раз: ffmpeg
python3 demo.py all scenarios/launch.json            # снять и собрать
python3 demo.py record scenarios/launch.json         # только съёмка (raw/launch.mp4)
python3 demo.py compose scenarios/launch.json        # только сборка (out/launch-{wide,tall}-{en,ru}.mp4)
python3 demo.py frames out/launch-wide-ru.mp4 5 20   # кадры для проверки глазами
```

Нужен телефон по adb с запущенным приложением и ANDROID_HOME для сборки приложения. Результат: `wide` 1920×1080 (телефон слева,
текст справа) и `tall` 1080×1920 (телефон сверху, текст внизу). Папки `raw/`, `out/`, `node_modules/` в git не попадают.

## Сценарий (`scenarios/*.json`)

- `setup` и `settle`: шаги до начала записи и пауза после них, чтобы первый кадр был уже «в сцене».
- `steps`: `{t, step, ...}` в секундах от начала записи.
- `subtitles`: `{from, to, en, ru}`. Новая версия языка — новое поле в каждой реплике.
- `duration`: длина записи в секундах (лимит screenrecord 180).

## Шаги сцены (приёмник `DEBUG_SCENE`, только `adb shell`)

| step | параметры | что делает |
|---|---|---|
| `profile` | `data=character=puf[;accessory=glasses]` | персонаж и наряд постановочного человека; ничего не сохраняется |
| `face_in` / `face_out` | `name`, `id` | человек появился (узнан) или ушёл |
| `wake` | `text` | сказали wake-word |
| `command` | `intent`, `data=k=v;k=v` | та же команда, что приходит от звука (`character_glasses`, `time`, `weather`…) |
| `say` | `text` | Зюзя говорит через настоящий модуль звука |
| `note` | `text` | подпись «записка» на экране |
| `sleep` | | человек ушёл, приложение уходит в сон |
| `reset` | | выйти из сцены, вернуть реальную камеру |

Пока сцена идёт, настоящая камера не слушается (чтобы случайный прохожий не испортил дубль); `reset` возвращает её.
Приложение реагирует на шаги как на настоящие события, но «записка» здесь произносится голосом по тексту, а не берётся из очереди записок.

## Ограничения

- `screenrecord` пишет только картинку: звук Зюзи в ролик не попадает, смысл несут субтитры (для X и LinkedIn автозапуск всё равно без звука).
- Первый кадр после установки нового APK может быть до загрузки экрана: запускайте приложение за несколько секунд до съёмки (скрипт ждёт 3 с).
